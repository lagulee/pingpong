# 탁구. — 1:1 실시간 탁구 게임

친구끼리 링크로 접속해 1:1로 겨루는 브라우저 탁구 게임입니다.
회전·마그누스 효과(회전하는 공이 휘는 현상)·바운드를 실제 탁구처럼 계산하고, 소리와 연출로 손맛을 살렸습니다.
PC(마우스)와 휴대폰(가로 화면, 터치)에서 모두 할 수 있습니다.

- 3D 그림: Three.js / 물리: 직접 작성한 결정론 엔진(같은 입력 → 모든 기기에서 같은 궤적)
- 서버: Cloudflare Workers + Durable Objects (무료 플랜)
- 소리: Web Audio로 직접 합성 (외부 음원 없음)

## 하는 법

1. 배포 주소에 들어가 **Ctrl+F5**(강력 새로고침)를 합니다. 화면 왼쪽 아래 버전명이 최신인지 확인하세요.
2. 첫 화면 탁구대에서 고릅니다.
   - **왼쪽 코트 = 연습**: 로봇과 경기합니다. 난이도는 쉬움·보통·어려움.
   - **오른쪽 코트 = 대전**: 닉네임을 쓰고 **방 만들기** → 방 코드(또는 링크)를 친구에게 보냅니다. 친구는 코드를 넣고 **입장**합니다.
   - **복식(2:2)**: **복식 방**을 만들면 4명이 들어올 수 있습니다. 대기실에서 **팀 옮기기**로 짝을 고르고 4명이 모두 준비하면 시작합니다.
   - **관전**: 친구가 만든 방 코드를 넣고 **관전**을 누르면 경기를 구경만 합니다(방마다 최대 8명). 마우스를 끌면 시점이 돌고 휠로 확대·축소, Space로 시점(왼쪽 선수 뒤·오른쪽 선수 뒤·옆·위)이 바뀝니다. 휴대폰은 **시점 바꾸기** 버튼을 쓰세요.
3. 11점 먼저(10:10이면 2점 차) 내는 쪽이 이깁니다. 서브는 2점마다, 듀스부터는 1점마다 바뀝니다.
4. 경기가 끝나면 결과 카드에 경기 요약 표(구질별 타격·득점, 최고 속도, 최대 회전, 최장 랠리 등)가 나옵니다.
5. 대전 중 누가 인터넷이 끊기거나 다른 앱으로 가면 경기가 **일시정지**됩니다. **30초 안에** 돌아오면 3·2·1 뒤에 점수 그대로 이어서 합니다(한 경기에서 한 사람이 끊겨 있던 시간은 모두 합쳐 90초까지). 치던 랠리는 끝까지 판정되므로, 끊긴 쪽이 칠 차례였다면 그 점수는 잃습니다. 경기 중 **나가기**는 지금처럼 바로 기권입니다.

## 조작법

### 공 치기 (PC 마우스)

- 라켓은 마우스를 따라 좌우·높이로 움직이고, 앞뒤는 자동입니다.
- **왼쪽 버튼을 누른 채 휘두르면** 스윙, 누른 채 멈춰 있으면 **블록**입니다.
- 공이 날아오면 고리가 나타납니다. 고리(= 라켓 크기 = 칠 수 있는 범위)에 공이 올 때 휘두르세요. 타이밍에 따라 PERFECT·GOOD·OK.
- 고리 색: **빨강** = 스매시를 할 수 있는 높은 공, **노랑** = 낮은 공.

조작 모드는 설정(⚙ 또는 Tab)에서 고릅니다.

| 기본 모드 (처음 설정) | 고급 모드 |
|---|---|
| 위로 휘두르기 = 드라이브(탑스핀) | Q + 휘두르기 = 드라이브 |
| 아래로 휘두르기 = 커트(백스핀) | W + 휘두르기 = 커트 |
| 곡선으로 휘두르기 = 사이드(횡회전) | E + 휘두르기 = 사이드 |
| 높은 공을 아래로 빠르게 = 스매시 | R + 휘두르기 = 스매시 |
| 낮은 공을 아래로 빠르게 = 센 커트 | W+E = 사이드 커트, Q+E = 사이드 드라이브 |

- 들어온 공의 회전이 내 타구에 영향을 줍니다. 받을 공 고리 위의 **회전 표지**(↻ 탑 / ↺ 백 / ⟲ 횡 + 세기 칸)를 읽고 맞는 구질로 받아치세요.
- 같은 회전을 되받아치면 회전이 쌓입니다(상한에 닿으면 MAX SPIN).
- PERFECT를 연달아 치면 **퍼펙트 콤보**로 위력이 세집니다.

### 서브

- 내 차례에 **클릭**하면 그 자리에서 공을 띄우고, 공이 고리에 올 때 휘둘러 칩니다(휴대폰은 화면을 대는 순간 토스).
- 기본 모드: 위로 = 탑 · 아래로 = 백 · 곡선 = 사이드 서브. 고급 모드: 버튼 없이 = 무회전 · Q 탑 · W 백 · E 사이드.
- 점선(서브 가이드, G)이 예상 궤적과 첫 바운드 위치를 보여 줍니다.

### 키

| 키 | 기능 |
|---|---|
| Tab | 설정 열기/닫기 |
| Space | 시점 바꾸기 (비스듬한 시점 ↔ 정면, 관전 중에는 시점 프리셋 순환) |
| 마우스 휠 | 시점 거리 (멀리/가까이) |
| 마우스 드래그 | 관전 중에만: 시점 회전 |
| G | 서브 가이드 켜기/끄기 |
| M | 소리 끄기/켜기 |
| V | 속도·회전 화살표 |
| P / Esc | 일시정지 (연습만) |
| 1 · 2 · 3 | 난이도 쉬움 · 보통 · 어려움 (연습만) |
| N | 새 게임 (연습만) |

### 휴대폰

- 가로 화면으로 돌리고 ⛶로 전체 화면을 켜세요.
- **한 손가락**으로 조작합니다. 손가락을 대고 있으면 버튼을 누른 상태이고(멈추면 블록, 쓸면 스윙), 라켓은 손가락 조금 위에 뜹니다.
- 고급 모드에서는 왼쪽 아래 구질 버튼(드라이브·사이드 드라이브·스매시 / 커트·사이드 커트·사이드)을 누른 채 다른 손가락으로 쓸어 칩니다.

### 개발·조정용 주소

- `?debug=1`: 물리·판정 값 슬라이더, 공 발사기. "현재 값 복사"로 바꾼 값을 보낼 수 있습니다.
- `?sound=1`: 효과음 시험
- `?mobile=1` / `?mobile=0`: 모바일 모드 강제 켜기/끄기

최신이 위에 있습니다. 버전 형식은 `v단계.수정번호`입니다.

### 11단계 — 경기 요약

#### v11.0 (2026-10-22)
- 경기가 끝나면 결과 카드에 **경기 요약 표**가 나옵니다: 득점·서브 득점·타격 수, 구질별 "타격 / 득점", 최고 속도(km/h), 최대 회전(rps), 최장 랠리.
- PERFECT 횟수와 최대 퍼펙트 콤보는 내 칸에만 보입니다(다른 사람 칸은 "-"). 복식은 네 사람 각자와 팀 합계가 나옵니다.
- 연습·대전·관전 모두 볼 수 있습니다. 경기 도중에 들어온 관전자나 다시 접속한 사람은 "입장 이후 기록"으로 표시됩니다. 연습은 끝까지 마친 경기에만 나옵니다.

### 10단계 — 끊김 일시정지

#### v10.0 (2026-10-22)
- 대전 중 선수 연결이 끊겨도 바로 기권패가 아닙니다. 경기가 멈추고 모두의 화면(관전 포함)에 "일시정지 · ○○ 연결 끊김 — 기다리는 중 (남은 N초)"가 뜹니다.
- 30초 안에 돌아오면 "재개 3·2·1" 뒤 점수 그대로 이어서 합니다. 한 번에 30초, 한 경기에서 한 사람당 합쳐서 90초를 넘기면 기권패입니다. 복식에서 두 사람이 끊기면 둘 다 돌아와야 다시 시작합니다.
- 기권 처리된 뒤에 돌아온 사람은 결과 화면(기권패)을 바로 봅니다.

### 9단계 — 정식 복식

#### v9.0 (2026-10-21)
- **복식 방**(2:2): 대전 코트의 **복식 방** 버튼으로 만들고, 친구 3명이 같은 코드로 들어옵니다. 대기실에서 팀 옮기기로 짝을 고릅니다.
- 정식 탁구 복식 규칙: 두 사람이 **번갈아** 치고, 서브는 **대각선**(내 코트 오른쪽 → 상대 코트 오른쪽), 서브 차례는 서버 → 상대 → 서버의 짝 → 상대의 짝 순으로 돌아갑니다. 순서가 아닌 사람은 칠 수 없고, 화면 위쪽에 "차례 ○○"가 보입니다.
- 라켓 4개가 보이고(동료·상대 둘째는 옅게), 한 명이 나가면 그 팀이 기권패입니다. 관전도 복식을 지원합니다.
- 다음 업데이트 예정: 일시정지·경기 요약·이모트·리플레이

### 8단계 — 관전

#### v8.0 (2026-10-21)
- **관전 모드**: 방 코드를 넣고 **관전**을 누르면 친구들의 경기를 구경할 수 있습니다(방마다 최대 8명). 관전 자리는 선수 자리와 따로이고, 자리가 없으면 "관전 자리가 가득 찼습니다"가 뜹니다.

- 관전 화면은 선수보다 0.5초 늦게 나오는 대신 공이 멈칫하거나 튀지 않습니다.
