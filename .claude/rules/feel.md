# 렌더링·타격감·디버그 사양

## 렌더링 (render.js)

- Three.js를 CDN(import map)으로 불러온다.
- 각 플레이어는 **자기 엔드 왼쪽 위**에서 탁구대를 내려다본다(6단계, `TUNABLE`의 `CAM_*`: 위치 (−0.7, −3.0, 1.45), 바라보는 점 (0.12, 0.3, −0.15), 시야각 50°). 대전 모드에서는 상대 쪽 화면이 180° 돌아간 시점이라 상대도 자기 기준 왼쪽 위에서 본다.
  - 이유: 비스듬히 보면 공의 깊이가 화면 가로 이동으로도 보여 높이와 헷갈리지 않고(바운드 지점이 잘 읽힘), 높은 포물선(네트 위 1.3 m까지)도 화면에 들어온다. 기존 시점은 네트 위 1.30 m부터 잘렸다.
  - **Space 키**(7단계, C에서 옮김. 스크롤 등 기본 동작은 막고 입력창에서는 무시)로 기존 시점(`RENDER.CAMERA_CLASSIC`, 정면 (0, −2.9, 0.85))과 바꾼다. 카메라 값은 화면 전용이라 대전 중에도 바꿀 수 있다(`TUNABLE_ONLINE_FREE`).
  - **시점 거리**(v7.5, `TUNABLE.CAM_DIST`, 기본 1, 0.8~1.8): 바라보는 점·방향·시야각은 그대로 두고 카메라를 k배 멀리 둔다(`input.js` `zoomCamera`). 새·정면·모바일 시점 모두에 적용. 설정 ⚙ 슬라이더와 게임 화면 위 마우스 휠로 바꾸고 이 브라우저에 기억한다(`pp-camdist`). 판정 보정 `dragScaleFor`에 거리를 적용한 카메라를 넣어 멀리서 봐도 같은 손놀림 = 같은 스윙이다(`tests/camera-zoom.test.js`).
  - 시점이 바뀌어도 드래그 판정이 같도록 사람 드래그 속도를 보정한다(input.md). 원근 투영은 직선을 직선으로 보내므로 곧은 드래그가 곡선(사이드스핀)으로 바뀌지 않고, 화면 45° 드래그는 라켓 평면에서도 약 45°다(`tests/tuning.test.js`).
- 물리 좌표계(z가 위)와 Three.js 좌표계(y가 위)의 변환은 `render.js` 한 곳에서만 한다.
- 물리는 고정 스텝, 그리기는 두 물리 상태 사이를 보간해 부드럽게 표시한다.
- 공 표면에 무늬를 넣고 실제 `ω`로 회전시켜 상대 구질을 읽을 수 있게 한다.
- 공의 그림자를 탁구대에 표시한다(높이 판단에 중요).

## 화풍 (7단계 수정: v7.7 툰 셰이딩·외곽선 → v7.8 탁구장 포스터, 사용자 승인 시안)

- **색 4가지 + 보조**(`index.html` `:root`): 종이색 `--cream` #efe9dc 바탕·판, 먹색 `--ink` #161616 선·글자, 탁구대 초록 `--green` #1f6f4a, 공 주황 `--lime`(이름은 v7.7 그대로) #ff7a1a 주 버튼·강조. 나 빨강 `--red` #e04a2b, 상대 파랑 `--blue` #2d5fa8, 서브·중립 노랑. 그러데이션 없음.
- **판·버튼**: 각진 모서리(최대 3 px) + 3 px 먹색 테두리 + 오른쪽 아래로 어긋난 그림자(인쇄물 느낌). 버튼에 마우스를 올리면 먹색으로 뒤집힌다.
- **글꼴**: 제목·숫자·버튼 = Black Han Sans(`public/fonts/`, SIL OFL 1.1, @fontsource 5.3.0의 woff2, 글자 묶음별로 필요한 파일만 받음, 외부 CDN 없음). 14 px 미만·본문 = 시스템 글꼴 굵게(작은 포스터 글꼴은 뭉개짐).
- **첫 화면**: 위에서 본 탁구대. 왼쪽 코트 전체가 "연습" 버튼, 네트, 오른쪽 코트 "대전"(방 만들기·코드·입장). 위에 큰 "탁구." 제목(마침표 = 주황 공)과 밑줄 닉네임 칸. 메뉴 색은 `--m-*`(공용 토큰을 가리킴).
- **경기 화면**: 3D 바탕·안개·바닥이 종이색, 상판 #1f6f4a(메뉴와 같은 색), 외곽선 #161616, 툰 3단 명암은 v7.7 그대로. 가운데 안내는 글자 테두리 대신 종이색 띠(첫 줄 포스터 글꼴, 득점은 띠 색: 내 득점 초록·실점 빨강·중립 노랑), 탁구대 먼 쪽을 가리지 않게 화면 24% 높이. 판정 글자·팝업은 먹색 테두리 글자 유지.
- **정리(v7.7)**: 왼쪽 위 = 상태 칩 + 짧은 키 안내(PC), 판정 아래 숫자는 스윙·공 속도·정점 대비 시각(세기는 디버그). 디버그 패널·사운드 테스트는 개발용이라 어두운 패널 그대로.

## 타격감·재미

| 기법 | 구현 |
|---|---|
| 히트스톱 | 스매시 순간 3~5 프레임 정지 |
| 화면 흔들림 | 타격 속도에 비례하는 진폭, 0.15 s 감쇠 |
| 공 궤적 꼬리 | 구질별 색상 (탑스핀 빨강, 백스핀 파랑, 횡회전 보라). 7단계: 판정용 회전으로 칠하고(바운드 뒤에도 유지) 회전 / 상한만큼 진하게 (`trailColor`, 최소 `TRAIL_MIX_MIN` 0.35) |
| 라켓 크기 (v7.9) | 화면의 라켓 원판 반지름 = 예측 정점 고리 반지름 = 칠 수 있는 범위(원, `HIT_RADIUS` 0.10 m, v7.10). 서브 범위 `SERVE_HIT_RADIUS`도 0.10 m(v7.11)라 크기가 같다(값을 넓히면 서브 때 커진다). 외곽선 굵기는 그대로 |
| 빗나감 표시 (v7.11) | 내가 받을 공을 못 맞히면 왼쪽 위(콤보 아래)에 `MISS_SHOW` 1.6 s: **빠름 N ms**(파랑)·**느림 N ms**(빨강) = 가장 빠르게 휘두른 순간 − 예측 정점, 타이밍이 GOOD 창 안이면 **빗나감 · 공은 라켓 왼쪽/오른쪽/위/아래**(노랑). 정점 `MISS_EARLY` 1.0 s 전 ~ `MISS_LOOK` 0.4 s 뒤의 스윙을 보고 정점 + 0.4 s에 판정(`input.js` `judgeMiss`·`missText`, main.js `updateMiss`). 서브·발사기는 제외 |
| 회전 표지 (7단계) | 내가 받을 공의 예측 정점 고리 위에 "↻ 탑 / ↺ 백 / ⟲ 횡 + 세기 칸 1~5"(`spinRead`, 디버그면 rps) |
| 구질 버튼 표시 (7단계) | PC: 화면 아래 가운데 Q·W·E·R 칩(누른 것이 빛남). 모바일: 화면 버튼 자체가 빛남 |
| 타격음 | 속도가 클수록 음량↑·음높이↑. 라켓, 테이블, 네트, 모서리 소리 구분 |
| 긴장 연출 | 매치포인트에 슬로모션 + 심장 박동음, 랠리가 길수록 관중 함성 증가 |
| 판정 팝업 | `PERFECT`, `SMASH!`, `EDGE!`, `MAX SPIN`(7단계, 내 타격의 회전 누적이 상한) 텍스트가 튀어 오름 |
| 조작 안내 (7단계) | 첫 경기 시작(연습·대전)에 조작표 안내판(누르면 닫힘, 최대 `INTRO_TIME` 8 s, "다시 보지 않기"는 이 브라우저에 저장). 일시정지 화면에도 같은 조작표와 **메인화면으로** 버튼 |

- 연출은 물리 이벤트 목록(`bounce`, `racket`, `net`, `edge`)을 받아 반응한다. 연출 코드가 물리 상태를 바꾸지 않는다.
- 히트스톱·슬로모션은 **화면 표시만** 멈추거나 늦춘다. 대전 모드에서 물리 시간은 멈추지 않는다(두 컴퓨터가 어긋나지 않도록).

## 사운드 (audio.js)

- 짧은 노이즈 버스트 + 감쇠 사인파를 섞어 Web Audio로 직접 합성한다.
- `playImpact(type, speed)`: 충돌 종류와 속도로 음량·음높이·감쇠 시간을 정한다.
- 저작권 있는 음원은 쓰지 않는다. 외부 효과음이 필요하면 CC0만 쓰고 출처를 `public/sounds/CREDITS.md`에 적는다.
- 브라우저 정책상 첫 클릭 전에는 소리를 낼 수 없으므로 시작 화면에서 클릭으로 오디오를 켠다.
- 소리 켜기·음량·관중 함성·심장 박동은 설정 ⚙ 패널에 둔다(v7.4). M 키 음소거는 그대로.

## 설정 패널 (v7.4, 오른쪽 위 ⚙)

- PC 34 px·모바일 44 px 톱니 버튼, 누르면 바로 아래에 패널(폭 270 px, 디버그 패널이 펼쳐져 있으면 그 왼쪽). 연습 경기 중 열면 일시정지, 닫으면 이어서 한다(대전은 멈추지 않음). Esc·✕·일시정지 화면 클릭으로 닫는다.
- **조작 모드**: 기본(스윙 방향으로 구질) / 고급(Q·W·E·R·화면 구질 버튼). 고르면 조작표·첫 화면 안내·서브 안내·상태 줄이 바뀌고, 기본 모드에서는 Q·W·E·R 칩·화면 구질 버튼을 숨긴다(input.md).
- **소리**: 소리 켜기(M), 음량, 관중 함성(`SND_CROWD`), 매치포인트 심장 박동(`SND_HEART`). **화면**: 정면 시점(Space), 시점 거리(휠), 서브 가이드(G, `FX_SERVE_GUIDE`), 화면 흔들림(`FX_SHAKE`), 진동(모바일, `FX_VIBRATE`). 연출 값은 `TUNABLE_TOGGLES`라 대전 중에도 바뀐다.
- 조작 모드·소리·음량은 이 브라우저에 기억한다(`pp-control`, `pp-muted`, `pp-volume`).
- **숨은 치트(v7.12)**: 맨 아래 흐린 "진솔쌤❤️" → 비밀번호 칸 → 맞으면 **공/수** 고르기(v7.16, `pp-cheat` = `attack`/`defense`, 공 💖·수 💕, 다시 누르면 끔). 수 = 위력·타이밍 기본, 도달 범위 탁구대 전체 + 손을 떼도 조준 블록 + 안 들어가면 무회전 공으로 다시 조준. 아래는 공의 내용: 타이밍 항상 PERFECT. v7.13부터 헛스윙 보정도 함께: 도달 범위 + `CHEAT.REACH_EXTRA` 0.03 m(화면 라켓·고리는 그대로). v7.15부터 스매시 가능 높이 절반(빨간 고리도 낮게) + 랠리 공격 스윙 속도·회전 최대 2배(들어가는 데까지). 다른 안내·표시는 없다.

## 디버그 패널 (debug.js, `?debug=1`)

- `constants.js`의 `TUNABLE` 값을 모두 슬라이더로 표시하고 즉시 반영한다. 묶음: 물리(게임 중력 `G_GAME` 포함) / 판정 / 구질(목표 정점 높이 포함) / AI / 연출 / 카메라 / 모바일.
- 공의 속도·회전 벡터 화살표, 최근 구질 판정 결과, FPS, 핑을 표시한다.
- **"현재 값 복사" 버튼**: 바뀐 값만 JSON으로 클립보드에 복사한다. 사용자가 이를 세션에 붙여 넣으면 Claude가 `constants.js`에 반영한다.
- 공 발사기: 원하는 속도·회전으로 공을 쏘아 물리를 눈으로 확인할 수 있게 한다.

## 모바일 모드 (6단계 모바일, v6.2)

- **감지** (`mobile.js` `detectMobile`): `?mobile=1`이면 켜고 `?mobile=0`이면 끈다. 그 밖에는 손가락 화면(`pointer: coarse`)이면서 화면 짧은 변이 `MOBILE.MAX_SHORT_SIDE`(1100 px) 이하일 때 켠다. 모드는 화면·품질·진동만 바꾸고, 터치 입력은 모드와 무관하게 작동한다(input.md).
- **화면**: `body.mobile` CSS로 바꾼다. 세로면 "가로로 돌려 주세요" 덮개, 전체 화면 버튼 ⛶(+ 가로 고정, 지원할 때만. 아이폰 사파리는 요소 전체 화면이 없어 버튼을 숨김), 노치 여백 `env(safe-area-inset-*)`. 스크롤·확대·길게 누르기는 `touch-action: none`, `user-select: none`, `-webkit-touch-callout: none`, viewport `user-scalable=no`, iOS `gesturestart` 막기로 막는다.
- **버튼(44 px 이상, 오른쪽 위)**: ⏸(P), ⛶, ⚙ 설정(맨 오른쪽). 소리·시점·서브 가이드·진동은 설정 안(v7.4, 예전 🔊·👁·🎯 버튼). 일시정지 화면에 난이도 쉬움·보통·어려움, 새 게임(N), 화살표(V), 메인화면으로.
- **구질 버튼(7단계, 왼쪽 아래 2×2)**: 위 드라이브·스매시, 아래 커트·사이드. 왼쪽 끝의 버전·디버그 🛠과 겹치지 않게 왼쪽 56 px부터, 크기 `MOB_BTN_SIZE`(64 px), `MOB_BTN_LEFT` 0이면 오른쪽 아래. 첫 화면에서는 숨긴다.
- HUD 제목은 숨긴다. 첫 화면에서 닉네임 입력칸에 자동 포커스하지 않는다(화면 키보드).
- **시점** (`touch.js` `mobileCamera`): PC 시점(`CAM_*`)에서 시야각 `MOB_CAM_FOV` 50 → 54°, 바라보는 점 높이 `MOB_CAM_TZ` −0.15 → −0.45 m만 바꾼다. PC 구도 그대로면 가로 휴대폰에서 타점이 화면 아래 65~80%에 있어, 라켓을 손가락 위에 띄우면 서브 타점 아래에 쓸 자리가 40 px뿐이었다(브라우저 점검). 대신 네트 위 약 1.4 m보다 높은 공은 화면 위로 잘린다. 세로 구도는 화면 비율과 무관하다.
- **성능** (물리 스텝은 그대로, 그리기만): 픽셀 비율 상한 `MOB_PIXEL_RATIO` 1.5, 그림자 지도 `MOB_SHADOW_SIZE` 1024(부드러운 그림자 끔, 공 그림자는 유지), 기기 픽셀 비율 2 이상이면 안티에일리어싱 끔(새로고침 때), 꼬리 점 개수 `MOB_TRAIL_SCALE` 0.5배. 자동 품질(`FX_AUTO_QUALITY`): 2 s 평균 FPS가 `MOB_FPS_MIN`(50)보다 낮으면 픽셀 비율을 0.25씩 낮춘다(최소 1.0).
- **진동** (`effects.js` `vibrationMs`, `FX_VIBRATE`): 내 라켓 타격 `VIB_HIT_MIN~MAX`(12~35 ms, 소리 세기와 같은 g로 단조 증가), 내 코트 바운드 `VIB_BOUNCE`(6 ms). 소리와 같은 화면 시각에 낸다. `navigator.vibrate`가 없으면(아이폰 사파리) 조용히 생략한다.
- **소리**: 잠금 해제를 첫 클릭 한 번이 아니라 `pointerdown`·`touchend`·`click`마다 다시 시도한다(iOS는 다른 앱에서 돌아온 뒤 다시 켜야 할 때가 있음). iOS 무음 스위치를 켜도 소리가 나게 `navigator.audioSession.type = 'playback'`(`SND_SILENT_SWITCH`, 지원하는 브라우저만. 다른 앱 음악이 멈출 수 있음).
- **화면 꺼짐 방지**: 연습·대전 중(일시정지 아닐 때) Screen Wake Lock. 화면을 다시 보면 다시 잡는다.
- **디버그 패널**: 🛠 버튼으로 접고 편다(모바일은 접힌 채 시작, 왼쪽 아래). "모바일" 묶음에 터치·품질·진동 값, 표시에 프레임 평균·최대 시간과 현재 픽셀 비율.
