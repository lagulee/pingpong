# 탁구 규칙 사양

## 구조

- `rules.js`는 물리 엔진이 내보내는 이벤트(`bounce`, `net`, `racket`, `floor`, `edge`)를 순서대로 받아 상태를 갱신하는 **상태 기계**다.
- 입력: 이전 상태 + 이벤트 1개 → 출력: 새 상태 + (있다면) 득점 결과
- 브라우저(연습 모드)와 서버(대전 모드)가 같은 코드를 쓴다.

## 상태

`{ score: [a, b], server, serveCount, phase, lastHitter, bouncesOnSide, winner }`
- `phase`: `waitingServe` → `serving` → `rally` → `pointOver` → (다음 서브) / `gameOver`

## 점수

- 11점제. 10:10부터 듀스(2점 차가 날 때까지 계속)
- 기본 1게임 단판. 이후 3게임 2선승제 옵션을 추가할 수 있게 구조를 둔다.

## 서브

- 서브권은 2점마다 교대, 듀스(10:10 이후)에서는 1점마다 교대
- 서브한 공은 **자기 코트에 한 번** 바운드 → 네트를 넘어 **상대 코트에 한 번** 바운드되어야 한다.
- 네트에 닿고 상대 코트에 정상적으로 들어간 서브 → **렛**(점수 없이 다시 서브)
- 네트에 닿고 들어가지 않은 서브, 자기 코트에 바운드되지 않은 서브 → 실점
- 토스한 공을 치지 못하고 떨어뜨림: 연습 모드는 점수 없이 다시 토스(`retoss`), **대전 모드는 서브 실점**(`tossMiss`, "토스 실패"). `createRules({ retoss: false })`로 고른다.

## 랠리 중 실점 조건

- 상대 코트에 바운드되지 않고 나간 공(아웃)
- 자기 코트에 바운드된 공을 치지 못하고 두 번째 바운드가 됨
- 상대 코트에 바운드되기 전에 공을 침(발리): 탁구대 위에 있거나 그대로 두면 자기 코트에 떨어질(인플레이) 공을 건드린 경우만
- 이미 탁구대 밖에 있고 자기 코트에 떨어지지 않을 공은 건드려도 발리가 아니라 상대의 아웃 (ITTF 오브스트럭션 규정)
- 같은 사람이 연속으로 두 번 침
- 모서리(`edge`)에 맞은 공은 유효(득점 인정). 옆면에 맞은 공은 아웃

## 검증 테스트 (tests/rules.test.js)

- [ ] 0:0에서 서브권이 2점마다 정확히 교대한다.
- [ ] 10:10 이후 1점마다 서브권이 교대하고, 2점 차가 나야 게임이 끝난다.
- [ ] 11:9에서 게임이 끝나고, 11:10에서는 끝나지 않는다.
- [ ] 네트 맞고 들어간 서브는 렛이 되어 점수가 그대로이다.
- [ ] 자기 코트 바운드 없는 서브는 실점이다.
- [ ] 투 바운드, 발리, 아웃, 연속 타격이 각각 올바른 쪽의 실점이 된다.
- [ ] 모서리에 맞은 공은 유효하다.
- [ ] (`tests/net.test.js`) 대전 규칙(`retoss: false`)에서 토스한 공을 치지 못하면 서브 실점 `tossMiss`, 연습은 토스 다시.
