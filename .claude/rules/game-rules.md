# 탁구 규칙 사양

## 구조

- `rules.js`는 물리 엔진이 내보내는 이벤트(`bounce`, `net`, `racket`, `floor`, `edge`)를 순서대로 받아 상태를 갱신하는 **상태 기계**다.
- 입력: 이전 상태 + 이벤트 1개 → 출력: 새 상태 + (있다면) 득점 결과
- 브라우저(연습 모드)와 서버(대전 모드)가 같은 코드를 쓴다.

## 상태

`{ score: [a, b], server, serveCount, phase, lastHitter, bouncesOnSide, winner }`
- `phase`: `waitingServe` → `serving` → `rally` → `pointOver` → (다음 서브) / `gameOver`

## 점수

- 11점제. 10:10부터 듀스(2점 차가 날 때까지 계속)
- 기본 1게임 단판. 이후 3게임 2선승제 옵션을 추가할 수 있게 구조를 둔다.

## 서브

- 서브권은 2점마다 교대, 듀스(10:10 이후)에서는 1점마다 교대
- 서브한 공은 **자기 코트에 한 번** 바운드 → 네트를 넘어 **상대 코트에 한 번** 바운드되어야 한다.
- 네트에 닿고 상대 코트에 정상적으로 들어간 서브 → **렛**(점수 없이 다시 서브)
- 네트에 닿고 들어가지 않은 서브, 자기 코트에 바운드되지 않은 서브 → 실점
- 토스한 공을 치지 못하고 떨어뜨림: 연습 모드는 점수 없이 다시 토스(`retoss`), **대전 모드는 서브 실점**(`tossMiss`, "토스 실패"). `createRules({ retoss: false })`로 고른다.

## 랠리 중 실점 조건

- 상대 코트에 바운드되지 않고 나간 공(아웃)
- 자기 코트에 바운드된 공을 치지 못하고 두 번째 바운드가 됨
- 상대 코트에 바운드되기 전에 공을 침(발리): 탁구대 위에 있거나 그대로 두면 자기 코트에 떨어질(인플레이) 공을 건드린 경우만
- 이미 탁구대 밖에 있고 자기 코트에 떨어지지 않을 공은 건드려도 발리가 아니라 상대의 아웃 (ITTF 오브스트럭션 규정)
- 같은 사람이 연속으로 두 번 침
- 모서리(`edge`)에 맞은 공은 유효(득점 인정). 옆면에 맞은 공은 아웃

## 복식 (9단계, 정식 ITTF)

`createRules({ doubles: true })`. 팀은 단식의 쪽(side)이고 팀 안의 두 사람은 **좌석** seat 0/1이다. 단식 규칙·결과는 그대로이고, 복식일 때만 아래가 더해진다.

- **서브 4순환**: 첫 서버 s0(첫 서브 팀)·첫 리시버 r0(상대 팀)이면 서브 차례 n(= `serveInfo`의 `turns`)마다 n%4 = 0: s0 → r0 / 1: r0 → s0의 짝 / 2: s0의 짝 → r0의 짝 / 3: r0의 짝 → s0. 2점마다(듀스는 1점마다) 차례가 넘어가므로 팀은 번갈아 서브하고 네 사람이 모두 서브한다(`doublesRoles`). 상태에 `serverSeat`·`receiverSeat`가 들어 있다.
- **타격 순서**: 한 포인트에서 [서버, 리시버, 서버의 짝, 리시버의 짝]을 되풀이한다(`hitOrder`, `rules.hits` = 이 포인트의 타격 수). 지금 칠 사람은 `expectedHitter`, 좌석까지 보는 `canHitSeat`. 차례가 아닌 사람이 치면 그 팀의 실점 `wrongPlayer`("순서 틀림", 서버·클라이언트는 미리 거르므로 방어용).
- **대각선 서브**: 서버 기준으로 자기 코트의 **오른쪽 반**에 먼저 튀고, 받는 사람 코트의 **오른쪽 반**(= 서버 기준 왼쪽)에 떨어져야 한다. 틀리면 서브 폴트 `serveHalf`("서브 코트 틀림 (대각선으로)", 네트에 닿은 서브도 틀린 반이면 렛이 아니라 폴트). 가운데 선(`RULES.CENTER_TOL` 3 mm)은 맞는 쪽으로 본다(`inRightHalf`). 랠리 중에는 어느 반이든 상관없다.
- **다음 게임**(3게임제): 첫 서브 팀은 지난 게임의 반대 팀, 그 팀의 첫 서버는 지난 게임의 첫 리시버, 첫 리시버는 지난 게임의 첫 서버다.
- 복식 서브 조준(`classifyShot(…, { diag: true })`): 착지 목표는 서버 기준 x ∈ [−`SERVE.DIAG_X_MAX`, −`DIAG_X_MIN`], 자기 코트 첫 바운드가 왼쪽 반으로 가면 착지점을 가운데 쪽으로 옮기고, 횡회전 서브는 회전 방향·크기(`DIAG_SPIN_SCALES`)를 바꿔 본다. 사람은 오른쪽 반(x ≳ 0.2)에서 토스해야 한다(서브 가이드 G가 복식에서는 대각선을 보여 준다).

## 검증 테스트 (tests/rules.test.js)

- [ ] 11:9에서 게임이 끝나고, 11:10에서는 끝나지 않는다.

- [ ] 투 바운드, 발리, 아웃, 연속 타격이 각각 올바른 쪽의 실점이 된다.
- [ ] 모서리에 맞은 공은 유효하다.
- [ ] (`tests/net.test.js`) 대전 규칙(`retoss: false`)에서 토스한 공을 치지 못하면 서브 실점 `tossMiss`, 연습은 토스 다시.
